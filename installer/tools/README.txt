Eaton 5E UPS WinUSB Driver Tools
=================================

eaton_winusb.inf - Custom WinUSB driver INF for Eaton UPS devices
                   with VID 0463 and PID FFFF.

The MSI invokes Install-WinUSBDriver.ps1 to install this driver. If automatic
installation fails, Zadig (https://zadig.akeo.ie) can install WinUSB manually.
